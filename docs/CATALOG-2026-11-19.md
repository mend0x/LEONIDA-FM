## Cómo interpretar las etiquetas

- `OFFICIAL` + `STATION_PREVIEW`: material previamente atribuido al adelanto presentado por Rockstar; no implica que tengamos derechos para emitirlo.
- `REPORTED` + `SECONDARY_STATION_LIST`: nueva asociación documentada en GTABase el 19/11/2026; **no se ha comprobado individualmente en el juego** ni se clasifica como confirmación directa de Rockstar.

Fuentes principales: https://www.rockstargames.com/VI/music y https://www.rockstargames.com/newswire/article/o3982oa93a23k4/the-music-of-grand-theft-auto-vi-in-game-radio-stations

No se han añadido archivos de música, URLs de descarga ni códigos de YouTube para estos 71 temas. Son **metadatos y referencias bibliográficas**, no una nueva fuente de reproducción. LEONIDA FM sigue reproduciendo radios online externas del género correspondiente mediante Radio Browser; los anuncios y la programación son los de cada operador.

## Cómo actualizar

Edita `data/station-track-additions.json` y ejecuta `npm run catalog:sync`. Para mantener la trazabilidad, incluye URLs y fechas, y utiliza `REPORTED` hasta disponer de confirmación oficial independiente. Las emisoras nuevas se configuran mediante `npm run station:add` y `data/radio-genres.json`.
